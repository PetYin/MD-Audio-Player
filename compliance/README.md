# 许可、源码与来源材料

核对日期：2026-10-16。这些材料随源码包和 Windows 便携包放在根目录 `compliance/`，便于在离线环境查看已附源码、许可和构建修改记录。

- [Electron 的 FFmpeg DLL 源码、构建与替换](ELECTRON_FFMPEG_SOURCE.md)：精确版本、源码附件、GN 配置、联网重建步骤和验证缺口。
- [FFmpeg 8.0 命令行构建修改](FFMPEG_CLI_CHANGES.md)：原始源码、实际修改、编译选项、二进制身份与日期说明。
- [机器可读来源记录](source-provenance.json)：官方 URL、修订、归档 SHA256、实际二进制核对及材料范围。
- [规则清单](rules-manifest.json)：内置分类和配方文件的哈希、条目数与权利状态。
- `sources/`：本次实际随包提供的源码，不是下载占位链接。

`sources/` 保留官方源码中的测试图片、测试音调、视频、文档截图及测试容器；它们不会作为播放器素材加载，也不是从游戏提取的音频。这些源码附件及其上游许可不能概括为“没有版权内容”。第三方许可、版权行和文件级声明保留在各源码归档内，运行时许可另见包内 `resources/vendor/licenses/` 和 `LICENSES.chromium.html`。

该目录提供可核查的来源与许可材料，不证明游戏内容或衍生元数据已经取得发布授权，也不构成法律意见或全部分发义务已满足的保证。尤其 Electron/Chromium 全量构建仍依赖按固定 DEPS 取得的额外源码和工具链；本次未完成该 DLL 的全量重建与替换实测。
